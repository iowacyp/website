# Iowa CYP Story Gallery Event Setup

The event display is available at:

`https://www.iowacyp.com/story-gallery/`

The page is public but unlisted. It does not appear in the website navigation, site search, sitemap, or search-engine results.

## Before the Event

1. Connect the iPad to reliable Wi-Fi.
2. Open the gallery URL in Safari.
3. Wait until the header says `Offline ready`.
4. Tap Safari's Share button and choose `Add to Home Screen`.
5. Open the new Iowa CYP Stories icon once while still connected to Wi-Fi.
6. Turn on Airplane Mode and reload the gallery to confirm it works offline.
7. Turn Airplane Mode off if event Wi-Fi will be available.

## During the Event

1. Open the gallery from the Home Screen icon.
2. Tap `Start slideshow` if the display will be unattended.
3. Visitors can tap the slideshow or any gallery photo to read the full story.
4. The display returns to slideshow mode after 90 seconds without interaction.
5. Use the large `All stories` button to return to the photo wall.

## Guided Access

Guided Access keeps visitors inside the story display.

1. In iPad Settings, open Accessibility, then Guided Access, and turn it on.
2. Open the Story Gallery.
3. Triple-click the iPad's top or Home button.
4. Choose `Start`.
5. Triple-click again and enter the Guided Access passcode to end the session.

## Updating the Offline Copy

After stories or images are changed:

1. Connect the iPad to Wi-Fi.
2. Open the gallery and leave it open until `Offline ready` appears.
3. Close and reopen the Home Screen app.
4. Test once in Airplane Mode before the next event.
